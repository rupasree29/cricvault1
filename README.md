# CricVault - Real-Time Cricket App

A modern, comprehensive cricket application featuring live ball-by-ball updates, interactive match schedules, team rosters, ICC standings, and full 11-18 player international squads for major cricketing nations.

## 🚀 Running on Your Desktop

### Prerequisites
- Node.js (version 18 or higher recommended)
- npm (comes bundled with Node.js)

### Quick Start
1. Unzip `cricvault-cricket-app.zip` to a folder on your Desktop.
2. Open a terminal (PowerShell, Command Prompt, or Terminal on macOS/Linux) in the unzipped folder.
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the local development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to:
   ```
   http://localhost:3000
   ```

## 🏏 Key Features
- **Live & Today Matches**: Real-time scoreboards, wagon wheels, ball commentary, run rate indicators.
- **Tomorrow & Upcoming Schedule**: Dynamic schedule with next 2-day filters and multi-country tour fixtures.
- **Teams Directory**: Complete national & domestic teams with captains, coaches, and colors.
- **Full Player Rosters**: 11-18 authentic players per nation (India, Australia, South Africa, England, New Zealand, Pakistan, West Indies, Sri Lanka, Afghanistan, Bangladesh) across Men's and Women's ODIs and T20s.
- **ICC Points Table**: World Test Championship, ODI Super League, and T20 International standings.
- **Statistics & Leaderboards**: Top run scorers, wicket takers, strike rates, and bowling economy.
